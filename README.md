# 照片变微信表情 · Photo to WeChat Stickers

一张照片，自动完成二维角色定妆、10款日常循环GIF、横幅/封面/图标、文案和预览，交付一个只含四个文件夹的ZIP。

## 下载与安装

[下载完整 Skill 安装包](photo-to-wechat-stickers.zip)

解压安装包，将其中的 `photo-to-wechat-stickers` 文件夹放入 `~/.codex/skills/`。完整源码、执行说明、参考记录、测试和示例均在安装包内。新开聊天并附上照片：

> 用 $photo-to-wechat-stickers，把这张照片直接做成一整套微信GIF表情，完成所有步骤后给我一个ZIP。

宿主需要图片生成工具、本地文件执行能力，以及 Python 3.10+ 和 Pillow。安装包包含 `requirements.txt`。不附带模型额度或账号密钥。

## 自动完成的内容

- 提炼照片特征，固定角色形象和二维风格。
- 自动起名，设计10条日常聊天短语和相应动作。
- 输出真实多帧循环GIF；原生动图不可用时，用连续动作帧合成并说明方式。
- 配图（横幅、封面、图标）、动图、文案、预览图分别归档。
- 交付前检查尺寸、体积、真实不同帧、帧时长、循环和指定透明度。

## 强制自审与返修

定妆、样稿以及每款最终动图都必须逐帧查看，检查肢体连接、角色花纹、文字、动作连续性和裁切。抬起爪子时，不能保留原来的落地前腿又新增一只手；合理遮挡按姿势判断。

`review_stickers.py` 导出全帧编号审查图，绑定文件摘要，并拦截待审、失败、漏帧、审查后修改及文件清单变化。检查通过后才能打包，内部报告不混入用户素材包。视觉判断由能看图的智能体完成，程序不冒充自动识别畸形的模型，也不保证零缺陷。

7项自动测试覆盖上述拦截机制与通过后的打包验证。解压后可运行：

```sh
python3 -m unittest discover -s tests -v
```

## 上传微信

默认完成本地素材包。用户另行要求上传时，协助操作官方页面；扫码、身份核验由本人完成。当前页面规格优先，素材完成不等于审核通过。真实账号上传和审核尚未端到端验证。
